# Short posts (X, LinkedIn, Bluesky, Mastodon)

Three variants. Each stands alone. Attach `brand/duck-1024.png`.

## 1. The story

Coding agents cost me a large amount of money this summer and delivered nothing.
So I built the thing that says no: Helmet Duck, hooks for Claude Code that
refuse blind overwrites, unevidenced commits and known-bad commands. First week
on my machine: 242 catches. Free, source visible. https://helmetduck.com

## 2. The mechanism

Everything you tell an agent is advice. Advice is what it skips when it decides
it already knows. Helmet Duck is not advice: a script, never the model, evaluates
the rule, and the harness refuses. Thinking cannot be gated. Its consequences
can. https://helmetduck.com

## 3. The honesty

Helmet Duck refuses nothing until you have read its risks page and accepted it.
The page lists fourteen risks, what limits each, and what you accept. That is
how a guard for agents should be sold. https://helmetduck.com/risks.html

## LinkedIn variant (longer)

After thirty years in IT and a retirement I did not choose, I spent the summer
running coding agents on my own projects. They cost a large amount of money in
tokens and delivered nothing: they worked from memory, edited files they never
read, committed without tests, and asserted every wrong thing with confidence.

Helmet Duck is what I built afterwards: hooks for Claude Code in which a script,
never the model, evaluates each rule and the harness refuses the action. In its
first week it caught the agent 242 times. It is free, the source is visible for
inspection, and it refuses nothing until you have read its risks page.

If your team runs agents on real code, the risks page is worth ten minutes even
if you never install it. https://helmetduck.com
